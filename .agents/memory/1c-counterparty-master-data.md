---
name: Правила мастер-данных 1С
description: Долговременные бизнес-правила сопоставления и проверки контрагентов из 1С.
---

1С является источником данных для ИНН, наименования и полного наименования контрагента. При первом импорте запись сопоставляется по ИНН, далее — по стабильному Id_1c. Обычные пользователи редактируют остальные поля, администраторы могут менять все поля. Новые записи требуют подтверждения администратора; удаление из 1С должно сохранять локальную операционную историю.

**Why:** пользователь определил 1С как источник ИНН и названий, но отдельно сохранил администраторам возможность исправлять эти поля вручную.

**How to apply:** обычным пользователям блокировать только три поля ИНН/названий в связанном с 1С контрагенте; администратору оставлять полный доступ. Новые API-поля добавлять через явный allowlist и не удалять связанные записи физически.
