---
name: Правила мастер-данных 1С
description: Долговременные бизнес-правила сопоставления и проверки контрагентов из 1С.
---

1С является источником истины для ИНН, наименования и полного наименования контрагента. При первом импорте запись сопоставляется по ИНН, далее — по стабильному Id_1c. Новые записи требуют подтверждения администратора; удаление из 1С должно сохранять локальную операционную историю.

**Why:** пользователь определил 1С как мастер-систему контрагентов и потребовал проверку новых записей и безопасное удаление.

**How to apply:** при развитии интеграции оставлять редактирование мастер-полей только за 1С, добавлять новые поля через явные allowlist-правила и не удалять связанные записи физически.
